# আমার বাংলাদেশ — নিউজ কার্ড অটোমেশন

নিউজের লিংক দিলে সাইট নিজে খবরটা পড়ে, DeepSeek দিয়ে হেডলাইন আর ছোট বিস্তারিত লেখে, তারপর "আমার বাংলাদেশ"-এর নকশায় ফটো কার্ড বানায়।
মালিক কার্ডটা দেখে দরকার হলে ঠিক করেন, তারপর অনুমোদন দেন। অনুমোদিত কার্ড ঠিক করা সময়ে ফেসবুক পেজে পোস্ট হয়।
**অনুমোদন ছাড়া কিছু পোস্ট হয় না।**

## কীভাবে চলে

| ধাপ | কোথায় |
|---|---|
| লিংক → নিউজ পড়া (og: ছবি, সাইটের নাম + Jina Reader-এ মূল লেখা) | `src/article.js` |
| DeepSeek → হেডলাইন, বিস্তারিত, ক্যাটাগরি, সূত্র | `src/ai.js` |
| কার্ড আঁকা — **ব্রাউজারে** (বাংলা যুক্তাক্ষর নিখুঁত আসে) | `public/card.js` |
| দেখা, ঠিক করা, অনুমোদন, সময়সূচি | `public/app.js` |
| সব তথ্য — একটা Durable Object (SQLite), ফ্রি প্ল্যানে চলে | `src/store.js` |
| প্রতি ৫ মিনিটে: বাকি লিংক লেখা, সময় হলে পোস্ট | `src/worker.js` (`scheduled`) |
| ফেসবুক পেজে ছবিসহ পোস্ট — বাছা সব পেজে, ক্যাপশনে লিংক ছাড়া | `src/facebook.js` |

পোস্টের সময় শুরুতে সকাল ৮টা থেকে রাত ১০টা, প্রতি ঘণ্টায় একটা (দিনে ১৫টা)। সাইটের **সময়সূচি** থেকে বদলানো যায়।
প্রতিটা সময়ে লাইনের প্রথম অনুমোদিত কার্ড যায়। লাইন খালি থাকলে সেই সময়টা বাদ পড়ে।

## Cloudflare-এ চালু করা (একবার)

1. Cloudflare → **Workers & Pages → Create → Import a repository** → এই রিপো। Worker-এর নাম: `amar-bangladesh-card-generator`।
   Build command খালি, Deploy command `npx wrangler deploy`।
2. Worker → **Settings → Variables and Secrets** → নিচেরগুলো **Secret** হিসেবে:
   - `ADMIN_PASSWORD` — সাইটে ঢোকার পাসওয়ার্ড
   - `DEEPSEEK_API_KEY` — DeepSeek-এর key
   - `FB_USER_TOKEN` — মালিকের স্থায়ী ফেসবুক লগইন-টোকেন। এর পরে সাইটের **সেটিংস → কোন ফেসবুক পেজে পোস্ট হবে**-তে পেজ বাছতে হয়;
     টিক দেওয়া সব পেজে একসাথে পোস্ট যায়। এক পেজে হয়ে আরেকটায় আটকালে আবার চেষ্টায় শুধু বাকিটায়।

⚠ key বা টোকেন কখনো কোডে বা GitHub-এ নয় — শুধু Cloudflare-এর Secret-এ।

## পরীক্ষা

- `npm test` — সময়সূচি, লিংক, AI-এর উত্তর পড়ার নিয়ম
- `npm run test:e2e` — পুরো পথ (নকল নিউজ সাইট, DeepSeek, ফেসবুক + আসল Worker কোড + আসল ব্রাউজার)।
  কার্ডের ছবি `test/.out/card.png`-এ। Windows-এ workerd-এর জন্য Visual C++ runtime লাগে (`test/e2e.mjs`-এর মন্তব্য দেখুন)।
